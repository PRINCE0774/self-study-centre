## How It Works

The website references images by relative paths:

- Navbar Logo:    <img src="images/logo.jpg">
- Hero Banner:    <img src="images/logo.jpg">
- Hero BG:        background: url("../images/interior-1.jpg")  (in css/style.css)
- Gallery Pic 1:  <img src="images/interior-1.jpg">
- Gallery Pic 2:  <img src="images/interior-2.jpg">
- Gallery Pic 3:  <img src="images/logo.jpg">
- Footer Logo:    <img src="images/logo.jpg">

## To Add More Images Later

1. Copy your new image into the `images/` folder
2. Add a new gallery item in `index.html` inside the `<div class="gallery-grid">`:

    <div class="gallery-item" onclick="openLightbox(this)">
        <img src="images/your-new-image.jpg" alt="Description" loading="lazy">
        <div class="overlay">
            <div class="overlay-icon"><i class="fas fa-expand"></i></div>
            <div class="overlay-text">Your Label</div>
        </div>
    </div>

3. Save and refresh the browser

## Important Notes

- Images MUST stay inside the `images/` folder
- File names are case-sensitive (logo.jpg != Logo.JPG)
- Supported formats: .jpg, .jpeg, .png, .webp
- Recommended size: 1920x1080 or larger for backgrounds
- The hero background is set in css/style.css line ~130
